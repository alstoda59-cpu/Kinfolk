# Kinfolk Social | First installable mobile alpha

**Scope:** the full main Kinfolk Social app, without a redesign, guest demo, or production release.

**Source branch:** `kinfolk-social/alpha-installable-build`, based on Recovery225. Main Kinfolk and Kinfolksworld production deployments are untouched.

## Verified native build

GitHub Actions: https://github.com/alstoda59-cpu/Kinfolk/actions/runs/40277708802

Two build jobs **succeeded** with the generated native `package-lock.json`:
- `kinfolk-social-android-alpha-debug`: Android Gradle `assembleDebug` output `app-debug.apk`. The APK is debug-signed for sideloading, **not** a Play Store AAB. CI debug certificates are ephemeral, so installing a later build may require uninstalling this one.
- `kinfolk-social-ios-simulator-unsigned`: ZIP containing the Xcode-built unsigned `App.app` **for iOS Simulator only**. It is not installable on a physical iPhone.

Both apps use an isolated alpha bundle identifier `social.kinfolk.alpha`, retaining the existing full Kinfolk UI and 24 referenced local scripts (including locally bundled Supabase JS, Reels and Channels). The public website is unchanged.

## Android installation for private testing

1. Sign in to GitHub and download the Android artifact from the successful run above, or use the APK attached to the ChatGPT delivery conversation.
2. The GitHub artifact ZIP contains `app-debug.apk`. Extract the APK to your Android phone.
3. Open the APK from Files/Downloads. If Android requests it, allow installation from that trusted source for this installation only.
4. Confirm the application opens as `Kinfolk Social Alpha`, that the Login and Create Account screens appear and that media/permissions behave normally. Do not interpret a successful install as proof of backend readiness.

The APK generated by this initial run may not update in place across new CI runs because its debug signing certificate can change. Preserve needed local data before uninstalling.

## iPhone installation blocker

The CI iOS simulator build **passed** but an unsigned simulator binary does not run on a physical iPhone. To install a private iPhone alpha, the owner must provide access to a Mac/Xcode signing setup, or an Apple Developer team/provisioning profile suitable for TestFlight or registered devices. Use an owner-controlled App ID, signing certificate and provisioning without committing passwords or keys.

Do not upload to TestFlight, submit to the App Store, or use any production distribution without explicit owner approval. Prepare a signed `iphoneos` build only after the signing identity and entitlement requirements are resolved.

## Backend and safety warning

**The current alpha APK retains the existing Supabase project connection.** There is **no authorized isolated alpha backend yet**. Avoid creating synthetic accounts, uploading test media, sending test messages, or changing privacy settings on real/shared user records until an isolated nonproduction environment and RLS checks are available. Installation/UI smoke testing is safe, but a real end-to-end test against the shared backend could modify live data.

The application is not yet verified for real signup/email, session recovery, profile updates, media uploads, messages, content age filtering and moderation. These require authorized test accounts on an isolated backend, physical Android/iPhone device tests, and launch-policy checks before opening an alpha to more users.

## Build locally from exact source

From `kinfolk-social/native`:

```bash
npm ci
npm run prepare:web
npm run alpha:verify
# Android on a machine with Android SDK and Java 21:
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
# iOS on macOS with Xcode:
# npx cap add ios
# npx cap sync ios
# npx cap open ios
```

Native dependencies are pinned and `package-lock.json` is committed; no runtime SDK CDN is required to render the locally packaged login screen. Actual account requests still need network access to the backend.

## Launch gate

The **private Android installable artifact** exists. The **iOS simulator build** exists. The work that remains is physical iPhone signing, isolated-backend testing, and real device acceptance. Do not claim a public app launch or store readiness based only on compile passes and mocked tests.

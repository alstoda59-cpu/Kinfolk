# Kinfolksworld

Kinfolksworld is the original 3D avatar and social-world expansion for Kinfolk Social.

## Current prototype
- Mobile-first 3D avatar stage using Three.js
- Avatar skin tone, hair style, hair color, outfit, height and build controls
- Saved local avatar state
- Public world browser and interactive room scenes
- Friend jump-in shortcuts
- Closet and creator marketplace demo
- Kin Coins demo wallet and item purchasing
- User-created room demo

## Integration plan
This module is intentionally isolated from the current Kinfolk production app while the core social app is being stabilized. The next integration layer should connect the existing Kinfolk Supabase session, profile identity, friends list, messages, inventory, moderation and creator-commerce data.

No IMVU code, branding, proprietary art or assets are used. Kinfolksworld is an original Kinfolk product.
